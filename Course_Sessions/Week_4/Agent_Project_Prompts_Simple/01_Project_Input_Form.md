# Project Input Form

Answer these questions **in your own words** before your first session. Don't overthink it — short, honest answers are perfect, and "not sure yet" is always allowed. The agent's first job (step 02) is to ask you questions and turn this into a proper plan.

**Already have a written proposal?** Just put its file path in question 0 — the agent will read it first, and you only need to answer whatever the proposal doesn't cover.

```text
MY PROJECT

0. Do I have a written project proposal?
   <file path to the document — or "no". If yes, read it first; I'll only fill in
    what it doesn't already answer.>

1. What is my project about?
   <2-3 sentences in plain words: what do I want to predict, detect, classify, or
    generate — and why is it interesting?>

2. My dataset:
   <link or file path, and roughly what's in it>

3. What should the model predict?
   <the thing the model outputs — e.g. "the wine quality score", "spam or not spam",
    "the house price">

4. Which models am I thinking of using?
   <just list them — the agent will help me sort out which are the main modern
    methods and which are simple baselines>

5. How many people in my group?
   <1-4>

6. What computer will I run this on?
   <e.g. laptop without GPU / laptop with GPU / free Google Colab>

Anything I'm unsure or worried about (optional):
   <e.g. "my dataset might be too small", "I've never used PyTorch">
```
